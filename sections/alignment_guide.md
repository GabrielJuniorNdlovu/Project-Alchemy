# Alignment guide for further development

Authority: ../goal.md. All chapter files in this folder are drafts pending review.

## Decisions before protocol completion

- Establish approved hardware access, delivered costs, complete connection topology and ethics route. Self-recording requires institutional review; do not assume exemption.
- Justify eight channel positions, referencing, sampling, task timing, breaks, repeated session schedule and usable trial requirements from inspected sources and pilot feasibility. The data are not yet established.
- Reserve independent final sessions. Decide development/validation/calibration allocations before collecting or unlocking evaluation data. Define a separate calibrated-session condition if needed.
- Prespecify primary risk–coverage operating points, useful command availability, model-selection criterion and analysis of dependent sessions. Numerical targets must be justified, not invented.
- Specify unfamiliar imagery and ensure no use for novelty-gate fitting or calibration. If infeasible, record the omitted experiment and request an explicit scope amendment.
- Fix causal preprocessing, latency timestamp definitions, command selection, armed/idle states, stale-command behaviour and independent robotic stopping arrangements.
