# 1 INTRODUCTION

**Dissertation title:** Risk-Aware Selective Decoding for Reliable Eight-Channel Motor-Imagery Brain–Computer Interfaces Under Distribution Shift

This chapter introduces the proposed wearable eight-channel motor-imagery brain–computer interface for live robotic-arm control and computer interaction using personally acquired EEG. It presents the background, research problem, aim and objectives, scope and limitations, feasibility, significance and work plan, with particular attention to reliable command acceptance under changing recording conditions.
